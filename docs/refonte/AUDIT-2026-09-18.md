# Audit et corrections — Lévy Notaires — 18 septembre 2026

## Périmètre et constat de départ

Audit du dépôt `thomaslevy-commits/site-internet-etude-notariale`, cloné au commit `b6ceb352063fb0f1a50ecc03228e49aae42c7ffb`, et inspection de l'accueil public dans le navigateur. Ce dépôt n'avait reçu aucune des deux refontes précédentes. La version présentée le 10 septembre restait dans une proposition de fusion sur la copie `docteurassouline-prog`.

Les observations de code portent sur les 38 pages publiques, leurs composants communs, le formulaire, les contenus et les dépendances. Les textes d'expertise et les articles ont été conservés. Cet audit technique et UX ne vaut ni audit juridique, ni certification RGAA.

## Dépendances ajoutées et maintenues

`react-markdown` corrige le rendu des contenus existants sans exécuter du MDX ou du HTML arbitraire. `mdast-util-from-markdown`, déjà utilisé indirectement par ce moteur, devient une dépendance directe pour produire un sommaire à partir de l'arbre syntaxique : les blocs de code ne sont pas confondus avec de vrais titres. Le remplacement ciblé de PostCSS évite une migration majeure vers Next.js 16 dans ce chantier.

## Vérifications avant livraison

`npm install`, `npm run dev`, `npm run typecheck`, `npm run lint`, `npm run verifier:contenu` et `npm run build` ont été exécutés. TypeScript, ESLint et compilation de production passent. Next.js génère 47 sorties ; la page Contact devient dynamique pour lire sa configuration serveur et le sujet demandé.

Les cinq tests de `node --test scripts/test-contact.mjs` passent : configuration absente/origine étrangère, limites du corps et JSON invalide, consentement/champs, échappement HTML/message suspect, refus/panne/expiration du prestataire. Le transport est simulé et aucun courriel réel n'a été envoyé.

`npm audit --omit=dev` ne signale plus aucune vulnérabilité le 18 septembre 2026. Cette mesure décrit le registre à cet instant et ne constitue pas une garantie générale de sécurité.

Le contrôle du HTML des 38 pages, incluant la page Contact rendue par le serveur de production local, vérifie 1 616 liens et ancres internes sans cible manquante, ainsi qu’un seul H1 par page. Le repli du contact sans messagerie configurée répond en HTTP 200 et conserve le sujet dans le lien de courriel. La recette visuelle du site publié est consignée dans le compte rendu de livraison. Le navigateur distant ne peut pas atteindre le serveur local ; l'ancienne prévisualisation Vercel exige une connexion. Aucune recette mobile réelle ni mesure Lighthouse n'est annoncée sans exécution.
