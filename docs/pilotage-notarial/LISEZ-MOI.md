# Pilotage Notarial

Documents de conception pour le futur logiciel de gestion de dossiers de l'Etude notariale Thomas Levy.

## Fichiers

- **prototype-pilotage-notarial.html** : prototype interactif complet (31 dossiers fictifs, 7 vues par role, workflow 20 etats, controles LCB-FT, tri intelligent des mails).
- **conception-pilotage-notarial.html** : document de conception en 12 livrables (cartographie utilisateurs, modele de donnees, workflows BPMN, roles/permissions, ecrans, architecture, integrations, automatisations, registre des risques, backlog, plan MVP 6 mois, criteres d'acceptation).

## Origine

Ces documents ont ete crees dans Claude Chat / Cowork (septembre 2026) et integres au depot le 06/09/2026.

## Statut

Phase de conception / prototypage. Aucun code de production n'a ete ecrit.
